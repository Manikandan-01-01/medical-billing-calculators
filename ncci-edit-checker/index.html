Key takeaways

  • An NCCI PTP edit pays the column 1 code and denies the column 2 code.
  • Modifier indicator 0 means no modifier can bypass the edit.
  • Modifier indicator 1 means an NCCI PTP-associated modifier can bypass it, only for a separate encounter, site or specimen.
  • CMS updates the edits every quarter. This tool uses the Q4 2026 file.

What is an NCCI PTP edit?

An NCCI PTP edit is a CMS code pair that should not be reported together for the same patient on the same date of service. The column 1 code is the code Medicare pays, and the column 2 code is the one it denies. The denial stands unless a clinically appropriate NCCI PTP-associated modifier is reported (CMS NCCI PTP edits page).

PTP stands for procedure-to-procedure. The NCCI bundling checker searches every active edit in the CMS practitioner file for your 2 codes, in both directions.

What do NCCI modifier indicators 0, 1 and 9 mean?

The modifier indicator tells you if a modifier can bypass the edit. The Correct Coding Modifier Indicator (CCMI) is the CMS name for this field (NCCI Policy Manual 2026, Ch. 1, §E).

Indicator 9 appears only on deleted edits. The checker shows active edits only, so you will see 0 or 1.

Which modifiers can bypass an NCCI edit?

Only NCCI PTP-associated modifiers can bypass an edit with indicator 1. The 2026 policy manual lists them in 3 groups (NCCI Policy Manual 2026, Ch. 1, §E):

  • Anatomic: E1–E4, FA, F1–F9, TA, T1–T9, LT, RT, LC, LD, RC, LM, RI.
  • Global surgery: 24, 25, 57, 58, 78, 79.
  • Other: 27, 59, 91, XE, XS, XP, XU.

Modifiers 22, 76 and 77 are not on the list, so they do not bypass a PTP edit. A modifier is allowed only when the clinical facts justify it, never just to get past the edit.

When is modifier 59 or XS correct for an NCCI edit?

Use 59 or an X modifier only when the 2 services were at different anatomic sites or different patient encounters. Different procedures alone do not qualify, and different diagnoses are not enough either (NCCI Policy Manual 2026, Ch. 1, §E). Use XE, XS, XP or XU instead of 59 when one of them describes the case. The modifier 25 vs 59 helper walks you through the choice.

For example, the manual says 38221 and 38220 can be billed with modifier 59 when the biopsy and aspiration are on opposite iliac bones. On the same iliac bone at the same encounter, use 38222 instead. When a modifier 59 claim still denies, I check the anatomic site in the note first. What data does the NCCI edit checker use?

The checker uses the CMS Medicare NCCI PTP edits for practitioner services, version v323r0, effective October 1, 2026. The 4 CMS files hold 2,637,645 records. We kept the 1,732,820 edits that are active today, across 10,881 column 1 codes, and dropped deleted edits (CMS NCCI PTP edits page).

The data loads in small parts, so a check downloads only the slices for your 2 codes. Hospital outpatient edits and Medicaid NCCI edits are separate files and are not included. CMS posts the next quarterly file for January 1, 2027.

How do you use the NCCI bundling checker?

  1. Enter the 2 codes billed for the same patient on the same date of service.
  2. Press Check NCCI edit. The tool looks in both directions.
  3. Read the result. Indicator 0 means bill only the column 1 code. Indicator 1 means a modifier may apply if the record supports it.
  4. Check units next with the MUE lookup for each code.

To search the CMS tables by hand, follow our guide to searching NCCI PTP tables. A bundled line often denies as CO-97.

Frequently asked questions

Is this NCCI edit checker free?

Yes. It is free and needs no sign-up. The codes you enter stay in your browser. The tool downloads only the part of the CMS edit file it needs.

Which NCCI file does the checker use?

It uses the Medicare NCCI PTP edits for practitioner services, version v323r0, effective October 1, 2026. Hospital outpatient edits are a separate file and are not included.

Does the order of the two codes matter?

No. Enter the codes in any order. The checker looks for an edit in both directions and tells you which code is column 1 and which is column 2.

Can modifier 25 bypass an NCCI edit?

Yes, when the edit has modifier indicator 1 and the E/M visit is significant and separately identifiable. Modifier 25 is one of the global surgery modifiers the policy manual lists as NCCI PTP-associated.

Do commercial payers use NCCI edits?

Many do, but not all, and some add their own edits. Medicaid programs use a separate Medicaid NCCI file. Check the payer policy when the claim is not Medicare.

How often do NCCI edits change?

CMS updates the PTP edit files every quarter. The next update is effective January 1, 2027, and we will load it then.
