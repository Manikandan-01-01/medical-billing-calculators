How to use this lookup

  1. Type a code the way it appears on the remittance (for example CO-16, co16 or 16), or a keyword from the description.
  2. Optionally filter by category or group code (CO, PR, OA, PI, or n/a for remark codes).
  3. Open the guide link for a code-by-code fix when one is published on Medical Billing 101.

A group code plus a CARC plus any RARC is the full denial reason. Unprocessable claims (for example Medicare claims returned with MA130) are not denials and usually have no appeal rights; correct the claim and resubmit.
