NPI Lookup

Look up any provider's National Provider Identifier (NPI) in seconds. Search by the 10-digit NPI, or by a provider's last name or an organization's name and state. Results come live from the official CMS NPPES NPI Registry.

Key takeaways

  • An NPI is a 10-digit number that identifies a health care provider on every HIPAA standard transaction, including claims.
  • Type 1 NPIs belong to individuals and Type 2 NPIs belong to organizations. Use the right one in the right claim box.
  • If the name, NPI or taxonomy on your claim does not match NPPES and the payer's file, expect a denial such as CO-206, CO-207 or CO-208.

How to use the NPI lookup

  1. Pick how you want to search. Choose NPI number if you have it. Choose Individual for a doctor, nurse or therapist, or Organization for a hospital, clinic, group or pharmacy.
  2. Fill in the fields. A name search needs a state. First name and city are optional and help narrow long lists.
  3. Read the results card. Each card shows the name, NPI, type, status, primary taxonomy code, other taxonomies, practice address, phone, enumeration date and last update.
  4. Open the official record. Use the NPPES link on the card when you need to show a payer or auditor the source.

What is an NPI number?

The National Provider Identifier (NPI) is a HIPAA Administrative Simplification standard. CMS describes it as a 10-position, intelligence-free numeric identifier. That means the digits say nothing about the provider, such as where they practice or their specialty. Covered providers, health plans and clearinghouses must use NPIs in HIPAA standard transactions in place of the older legacy provider IDs.

The last digit is a check digit. CMS calculates it with the Luhn formula on the first nine digits, using the prefix 80840, where 80 means health applications and 840 means the United States. This tool runs that same check before it sends any search, so a typo is caught right away.

NPPES is the National Plan and Provider Enumeration System, where NPIs are issued and stored. The public NPI Registry shows the parts of each NPPES record that CMS makes public.

Type 1 vs Type 2 NPI

  • Type 1 (individual): physicians, nurse practitioners, therapists, dentists and other individual providers. Sole proprietors are Type 1. An individual can have only one NPI.
  • Type 2 (organization): hospitals, nursing homes, group practices, home health agencies, labs and pharmacies. An organization can have more than one NPI, for example one for each subpart.

That split comes from the CMS NPI fact sheet. A provider who is incorporated can have both: a Type 1 NPI for themselves and a Type 2 NPI for their corporation or LLC.

Where the NPI goes on the CMS-1500 and UB-04

Medicare's CMS-1500 instructions and UB-04 instructions place each NPI in a set box. Other payers follow the same layout, but check their manuals for extra rules.

A missing rendering NPI often comes back with remark code N290. A billing NPI that the payer cannot match leads to CO-208.

Taxonomy codes and the NPI

A taxonomy code is a 10-character code from the Health Care Provider Taxonomy code set kept by the National Uniform Claim Committee (NUCC). It names the provider's type and specialty, for example 367500000X for a certified registered nurse anesthetist. Each NPPES record lists one primary taxonomy and can list more.

Some payers want the taxonomy on the claim. On the CMS-1500, NUCC uses qualifier ZZ in item 24I with the taxonomy in the shaded part of 24J, and the same qualifier in item 33b. Medicare does not generally require it. If a payer denies a service for the provider's type or specialty, as in CO-8, compare the taxonomy on the claim with the one in NPPES and on the payer's enrollment file.

How to update an NPPES record

Providers update their record by logging in to NPPES online. Some changes can be sent on paper with form CMS-10114. Federal rules say a covered provider must report changes to its required NPPES data within 30 days of the change (45 CFR 162.410). Moves, new practice locations and taxonomy changes are the usual reasons a lookup does not match the claim.

Keep in mind that an NPI does not prove a provider is licensed, credentialed or enrolled with a payer. A provider that is not set up with the payer can trigger CO-185 even with a valid NPI. When a claim is denied for any of these reasons, our appeal letter generator can help you draft a reply.

Frequently asked questions

Is this NPI lookup free?

Yes. It is free, needs no sign-up and has no search limit beyond a short pause if you send more than 20 searches in a minute. Results come from the public CMS NPPES NPI Registry.

Where does the NPI data come from?

Every search is sent to the official NPPES NPI Registry API (version 2.1) run by CMS. NPPES refreshes the API data daily, so what you see matches the public registry. We do not edit the data.

How do I find a doctor's NPI number?

Choose Individual, type the provider's last name, pick the state and press Search. Add a first name or city if you get too many matches. You can also add * after two or more letters, such as smi*, to match names that start with those letters.

What is the difference between a Type 1 and a Type 2 NPI?

A Type 1 NPI is for an individual provider, such as a physician, nurse practitioner or sole proprietor. An individual can have only one. A Type 2 NPI is for an organization, such as a hospital, group practice or pharmacy, and an organization can have more than one.

How do I check if an NPI number is valid?

Enter it in NPI mode. The tool first checks that it has 10 digits, starts with 1 or 2 and passes the Luhn check digit test with the 80840 prefix that CMS uses. It then looks the number up in NPPES to confirm it is on file.

Does an NPI mean the provider is licensed or enrolled with a payer?

No. CMS states that having an NPI does not ensure a provider is licensed or credentialed, does not guarantee payment and does not enroll the provider in any health plan. Check licensing with the state board and enrollment with each payer.

How do I update the information on an NPI record?

The provider, or a surrogate they authorize, logs in to NPPES and edits the record online. Federal rules require covered providers to report changes to their NPPES data within 30 days. Some changes can also be sent on paper form CMS-10114.

Is my search saved or shared?

No. This standalone copy runs in your browser and calls the public NPPES API directly. Nothing is stored on Medical Billing 101. The official registry may log requests on its side.
